# Проверки перед защитой

## Текущий статус

Исходники подготовлены. Структура и XML проверены на машине подготовки. Android SDK/JDK в доступной среде не найдены; компиляция, JUnit и тесты на телефоне **не выполнялись**. Пункты ниже являются чек-листом для команды, а не отчётом о пройденных испытаниях.

## Автоматические проверки

В Android Studio запустить `NutritionTest` или выполнить `gradlew.bat testDebugUnitTest`. Шесть тестов проверяют: контрольный расчёт обоих вариантов формулы и баланс БЖУ; отказ для несовершеннолетнего; NaN; неверное направление цели; приоритет аллергии над любимым продуктом и размер порции; сочетание ограничений и отсутствие рекомендаций при неподходящем остатке.

Затем `gradlew.bat assembleDebug`. Только успешная сборка создаёт APK; наличие исходников само по себе не подтверждает работоспособность приложения.

## Критерий готовности

Сборка и автоматические тесты проходят. Основной сценарий выполняется на реальном телефоне, включая перезапуск и офлайн-режим. Значения совпадают с ручным расчётом. Фильтры не пропускают размеченные запрещённые ингредиенты. Все участники понимают свой код и ограничения учебного каталога. Известные ошибки устранены или явно включены в список ограничений демонстрации.
