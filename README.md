# NutriFit — Android на Java

Учебная заготовка приложения для дневника питания и контроля веса. Все исходники приложения написаны на Java, интерфейс использует стандартные Android Views и XML. Веб-версии и сервера нет.

## Открыть и запустить

1. Распакуйте весь архив. В Android Studio выберите **Open** и папку `NutriFit`, где находится `settings.gradle`.
2. Установите Android SDK Platform 36 через SDK Manager. Для Gradle выберите JDK 17 в Settings → Build, Execution, Deployment → Build Tools → Gradle.
3. Дождитесь Gradle Sync. Первый запуск требует интернета для загрузки инструментов и JUnit. Gradle Wrapper включён в проект.
4. Создайте эмулятор Android 8.0 / API 26 или новее либо подключите Android-телефон с USB debugging.
5. Выберите конфигурацию `app` и нажмите Run.
6. Заполните профиль взрослого пользователя, сохраните, добавьте блюдо и порцию в граммах.

Зафиксировано: Android Gradle Plugin 8.13.0, Gradle 8.13, JDK 17, compile/target SDK 36, min SDK 26. Совместимость подтверждается [документацией Android](https://developer.android.com/build/releases/agp-8-13-0-release-notes).

После настройки SDK/JDK команды из папки проекта в Windows:

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Если SDK не найден, укажите его расположение в Android Studio; `local.properties` создаётся локально и не публикуется.

## Что уже написано

- Локальный профиль: имя, возраст, пол для формулы, рост, вес, желаемый вес, активность и цель.
- Выбор любимых/нелюбимых ингредиентов, аллергенов и четырёх ограничений питания.
- Оценка дневных калорий и БЖУ, проверка полей.
- Дневник по датам: блюдо, приём пищи, граммы, калории, БЖУ; удаление записей.
- Персональные предложения из восьми демонстрационных блюд с расчётом порции.
- Запись веса сегодня, история и простой график с временной шкалой.
- Сохранение дневника и веса в SQLite, профиля в SharedPreferences.
- Шесть JUnit-тестов для расчётов и фильтров.

Это **стартовые исходники, не проверенный готовый APK**. В среде подготовки не найдены Android SDK и JDK: сборка, JUnit и запуск на эмуляторе не выполнялись. Выполнена проверка структуры и XML. Обязательно пройдите `docs/TESTING.md` на своей машине.

## Границы заготовки

Один профиль на устройстве, без регистрации, пароля и облачной синхронизации. Создание профиля не называется авторизацией. Если учитель требует аккаунты, согласуйте расширение из технического плана.

Каталог и значения блюд демонстрационные, не проверенная база пищевой ценности. Фильтр знает только размеченные ингредиенты и аллергены, не гарантирует безопасность продуктов или отсутствие следов аллергенов. Взрослая формула не применяется к детям; для демонстрации используйте вымышленного взрослого.

Незаполненная анкета не сохраняется при повороте экрана. Сохранённые данные остаются. На прошлых датах дневника показывается текущая норма, а не исторический снимок. План питания на день, собственные продукты, редактирование порций и ввод веса задним числом пока не реализованы. При удалении приложения локальные данные теряются.
