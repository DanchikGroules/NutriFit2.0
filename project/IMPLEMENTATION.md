# Архитектура NutriFit 2.3

MainActivity управляет навигацией, отдельные Screen-классы связывают XML с данными. RecipeActivity показывает рецепт и масштабирует порцию. VideoActivity воспроизводит выбранный пользователем content URI через VideoView. LocalRepository использует последовательный Executor для SQLite, настроек и хеширования; RecyclerView переиспользует карточки, поиск отложен на 180 мс, устаревшие ответы не обновляют закрытый экран.

## Локальное хранение

`nutrifit.db`, SQLiteOpenHelper, версия 3:

| Таблица | Назначение |
| --- | --- |
| diary | Снимки названия, массы и БЖУ съеденного по датам |
| weights | Измерения веса по датам |
| catalog_items | 120 рецептов и 100 продуктов, отдельные поля состава и БЖУ |
| recipe_ingredients / recipe_steps | Упорядоченные ингредиенты и шаги |
| item_tags / item_allergens | Теги и аллергены со ссылками на каталог |
| catalog_text / lessons | Встроенные RU/EN/PL тексты и уроки |
| machine_translations | Кэш результатов API ML Kit по исходному тексту и языку |
| favorites | Ссылки на избранные элементы каталога |
| meal_plan | Дата, приём пищи, рецепт, порции, отметка переноса |
| shopping_checks | Отметки списка покупок по датам и ингредиентам |
| hydration | Миллилитры воды по датам |
| lesson_progress | Завершённые уроки и URI выбранного видео |
| app_meta | Версия наполнения каталога |

Миграция 1 → 2 добавляет таблицы, сохраняя дневник и вес. Первичное наполнение каталога выполняется транзакцией, повторный запуск не дублирует записи. Включены внешние ключи, индексы по датам дневника и плана. Перенос из плана в дневник и отметка consumed записываются одной транзакцией: повторный вызов не создаёт второй приём пищи. Покупки вычисляются из ещё не съеденных планов выбранного дня, одинаковые ингредиенты суммируются.

Профиль, аккаунт и флаг демо Plus хранятся в отдельных приватных SharedPreferences. Это локальное хранилище приложения, а не удалённый сервер. Удаление записи дневника не сбрасывает consumed у исходного плана: повторное добавление выполняется из каталога.

## Аккаунт

Один аккаунт на установку, имя/email/пароль. PBKDF2-HMAC-SHA256, 210000 итераций, случайная соль. Отдельные соль и хеш для случайного 128-битного кода восстановления. Код показывается при регистрации или обновлении через профиль, отправки email нет. Код действует до замены новым. Смена пароля требует текущий пароль; восстановление требует email и код и завершает сессию. Пять неудачных попыток вводят паузу 30 секунд. Это защита интерфейса локального учебного приложения, не полноценная серверная система идентификации.

## Контент и расширение

Каталог содержит авторские демонстрационные описания, 12 категорий по 10 рецептов; питательные значения вычислены из таблицы 100 продуктов. Готовая `catalog.db` поставляется внутри APK. При создании или обновлении личной/демо-базы таблицы импортируются в одной транзакции. Никаких JSON-описаний или JSON-парсера не используется. Миграция v2 сохраняет ID планов, избранное, дневник, воду, вес и прогресс; старую таблицу recipes удаляет только в успешно завершённой транзакции. Неизвестная ссылка прерывает обновление с откатом, а не удаляет записи. Наименования и ингредиенты доступны для поиска. Теги vegetarian/vegan/lactose_free/gluten_free и аллергены получены из состава. Рецепты не проходили независимую кулинарную или нутрициологическую экспертизу.

Видеоматериалы представлены ссылками с авторством. Никакие чужие видео не скачаны и не закрыты платной подпиской. Встроенные дополнительные текстовые уроки, план и покупки демонстрируют Plus. Реальные оплаты, Google Play Billing, сервер проверки покупок и права на коммерческие видеокурсы не реализованы: выбран режим для защиты проекта без списаний.

## Языки

AppCompatDelegate.setApplicationLocales переключает ru/en/pl, autoStoreLocales сохраняет выбор на старых Android. LocaleConfig включает системные настройки языка на Android 13+. Новые записи используют стабильные ключи приёмов пищи; прежние подписи отображаются на выбранном языке без изменения данных. Исходное содержимое в SQLite остаётся русскоязычным; SQL выбирает кэш ML Kit, а при его отсутствии — встроенный перевод. ContentLocalizer сопоставляет старые названия дневника с выбранным языком. Полный каталог и уроки доступны на ru/en/pl.

Детали кеширования, поиска и анимации: [LOCALIZATION.md](LOCALIZATION.md).

Подробная схема и миграции: [DATABASE.md](DATABASE.md). Для базы включён WAL; чтение каталога пакетное, связанные поля индексированы.
