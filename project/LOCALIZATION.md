# Языки и ML Kit · 2.3

Интерфейс переведён в Android XML-ресурсах на русский, английский и польский. Рецепты, продукты, ингредиенты, шаги, уроки и подписи видео читаются из SQLite.

## API перевода

Используется `com.google.mlkit:translate:17.0.3`. Экран «Язык / Language» предлагает подготовить английский или польский перевод через API ML Kit. Нажатие «Подготовить перевод» загружает необходимые модели по Wi-Fi (примерно 30 МБ на язык). Русский — исходный язык. Перевод выполняется на устройстве; ключ API и сервер не нужны.

TranslationViewModel сохраняет задачу при повороте экрана, показывает загрузку и прогресс перевода. Работа идёт в отдельном потоке. Выход из экрана отменяет ожидание и дальнейшую обработку. Ошибка загрузки/перевода показывает возможность повторить. Ограничение ожидания загрузки — 5 минут, одного текста — 60 секунд. Translator закрывается после использования.

API вызывается только для отсутствующих в кэше текстов. Полный результат записывается транзакционно в `machine_translations`; при ошибке неполный набор не сохраняется. После этого чтение и поиск используют SQLite без повторных обращений к API. Исторические названия дневника сопоставляются как со встроенными, так и с машинными переводами.

«Продолжить без загрузки» использует уже сохранённые переводы, а при их отсутствии — встроенные. Это позволяет открыть весь каталог даже без интернета при первом запуске. Машинный перевод может быть неточным. Числа, ингредиентные ID, БЖУ, порции и URL через переводчик не проходят. Аудиодорожки внешних видео не переводятся.

Аккаунт и записи дневника не передаются на перевод. ML Kit может отправлять Google диагностические данные SDK; сетевое разрешение также нужно для скачивания моделей.

Официальная документация: [Android Translation API](https://developers.google.com/ml-kit/language/translation/android), [поддерживаемые языки](https://developers.google.com/ml-kit/language/translation/translation-language-support), [данные SDK](https://developers.google.com/ml-kit/terms).

## Производительность

- Нормализованные таблицы вместо JSON-полей; каталог загружается тремя пакетными запросами, без отдельного запроса для каждого рецепта.
- Кэш моделей и Map для поиска по ID, предварительная нормализация поискового текста.
- Первичные ключи для связей, индексы категорий, тегов, аллергенов, дат и ссылок планов; WAL для чтения во время записи.
- Поиск с задержкой 180 мс, RecyclerView и DiffUtil.
- При смене языка кэш перестраивается; сама пользовательская запись не переписывается.

## Анимация

Лист и подписи появляются с лёгким увеличением, затем заставка плавно исчезает. Общая длительность около 1 секунды, один раз за процесс. Нажатие пропускает анимацию. Системное отключение анимаций и TalkBack учитываются.
