# SQLite: каталог и пользовательские данные

`app/src/main/assets/catalog.db` — единственный исходник каталога. Открывается обычными инструментами SQLite, например DB Browser for SQLite. Размер базы около 428 КиБ. В ней нет аккаунтов или дневников пользователей.

## Таблицы

| Таблица | Содержимое |
| --- | --- |
| catalog_items | ID, название, категория, признак продукта, время, граммы и БЖУ |
| catalog_text | Исходный русский текст и встроенные английский/польский переводы |
| recipe_ingredients | Рецепт, порядковый номер, ссылка на продукт, граммы |
| recipe_steps | Рецепт, порядковый номер, ссылка на текст шага |
| item_tags / item_allergens | Теги питания и аллергены |
| lessons | Уроки, авторство, ссылки на внешние видео, признак демо Plus |

Схема: `catalog_schema.sql`. Связи защищены внешними ключами, позиции и величины — ограничениями. Названия ингредиентов берутся из продукта: отдельной копии в каждом рецепте нет. Повторяющиеся шаги ссылаются на общий текст. JSON-файлов, JSON-полей и зависимости org.json нет.

На телефоне SQLiteOpenHelper создаёт приватную `nutrifit.db`, импортируя каталог в транзакции. Для демо используется `demo_nutrifit.db`. Дополнительно сохраняются diary, weights, favorites, meal_plan, hydration, shopping_checks, lesson_progress, app_meta и machine_translations. Пароли и профиль остаются в прежних приватных SharedPreferences; их перенос не нужен для изменения каталога.

## Обновление существующей установки

Версия схемы 3 поддерживает переходы с 1 и 2. Из v2 создаются новые таблицы каталога, избранное и планы копируются с прежними ID и ссылками; старый recipes с payload удаляется в той же транзакции. Дневник, вес, вода, отметки покупок, прогресс и аккаунт сохраняются. При нарушении связей SQLite откатывает всю миграцию. Обновлять нужно установкой APK поверх старого, без удаления приложения.

## Добавление рецептов

1. Сделайте копию catalog.db и включите `PRAGMA foreign_keys=ON` в редакторе.
2. Добавьте тексты в catalog_text и новый стабильный ID в catalog_items. Для продуктов используется префикс `product_`.
3. Заполните recipe_ingredients и recipe_steps с позициями от 0 без пропусков, теги и аллергены. БЖУ рецепта указываются на порцию, продукта — на 100 г.
4. Выполните `PRAGMA foreign_key_check` и `PRAGMA integrity_check`. Запустите `python project/check_database.py` (при расширении каталога обновите ожидаемые количества в проверке).
5. Для уже установленных приложений добавьте новую миграцию данных и увеличьте версию AppDatabase. Простая замена asset не перезаписывает пользовательскую базу. При изменении исходного текста обновите ссылку/текст и инвалидируйте соответствующий кэш machine_translations.

`python project/check_database.py` проверяет связи, полный перевод, состав, калории, 120 рецептов / 100 продуктов / 14 уроков и отсутствие JSON. `python project/check_translations.py` проверяет Android-ресурсы интерфейса.

Старые исходники сохранены локально в `delivery/legacy-json-before-sqlite.zip` и доступны в истории Git. Этот архив не входит в APK, исходный ZIP новой версии и репозиторий.
